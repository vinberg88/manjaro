Fix IP problems for X410. Cant find screen problems for WSL.

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

SABE IP FROM POWERSHELL HERE: 172.30.16.1

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in POWERSHELL so x410 works.

NOW GO BACK TO Manjaro Terminal and paste this.

yay -S systemd

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip here from powershell and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

Make a small script for MANJARO LINUX.

Type in terminal: sudo nano ~/.bash_deepin_desktop

Paste this in terminal and save:


#!/usr/bin/env bash

WINDOWS_HOST="$(awk '/^nameserver[[:space:]]/ {print $2; exit}' /etc/resolv.conf)"

export DISPLAY="${WINDOWS_HOST}:0.0"
export XDG_SESSION_TYPE="x11"
export XDG_CURRENT_DESKTOP="DDE"
export XDG_SESSION_DESKTOP="deepin"
export DESKTOP_SESSION="deepin"
export QT_QPA_PLATFORM="xcb"

if [[ -S /mnt/wslg/PulseServer ]]; then
    export PULSE_SERVER="unix:/mnt/wslg/PulseServer"
fi

Make a small script for MANJARO OS and DEEPIN DESKTOP.

COPY AND PASTE IN TERMINAL - NO STRESS - MANJARO LINUX - 2026

sed -i 's/\r$//' /tmp/deepin-arch-v2.sh
bash -n /tmp/deepin-arch-v2.sh && echo "Syntax OK"
sudo mkdir -p ~/.local/bin
sudo chown -R "$(id -un):$(id -gn)" ~/.local
install -m 755 /tmp/deepin-arch-v2.sh ~/.local/bin/deepin-arch
ls -l ~/.local/bin/deepin-arch
grep -qxF 'export PATH="$HOME/.local/bin:$PATH"' ~/.bashrc || echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
command -v deepin-arch
