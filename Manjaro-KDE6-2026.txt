Fix IP problem for X410. Cant find screen problem - MANAJRO AND KDE 6 PLASMA.

OPEN POWERSHELL FROM MICROSOFT AND TYPE: ipconfig

SAVE IP HERE FOR KDE 6 AND MANJARO: 172.30.16.1

NOTE - Importent to look for ip. Last lines are IP-numbers for WSL in POWERSHELL so xserver works.

NOW GO BACK TO MANJARO Terminal and paste this.

sudo systemctl unmask systemd-resolved.service
sudo systemctl enable systemd-resolved.service

sudo ls -l /etc/resolv.conf
sudo mv /etc/resolv.conf /tmp/resolv.conf.bak
sudo nano /etc/resolv.conf

nameserver 172.30.16.1 <-- put your ip number here from powershell and add nameserver.

sudo chattr +i /etc/resolv.conf
sudo systemctl restart systemd-resolved
sudo cat /etc/resolv.conf

NOW COPY AND PASTE THIS TO TERMINAL - TAKE ALL =) 

#!/usr/bin/env bash

# ----- X410 / X11 -----
export DISPLAY=${DISPLAY:-$(awk '/nameserver/ {print $2; exit}' /etc/resolv.conf):0.0}
export QT_QPA_PLATFORM=xcb
export GDK_BACKEND=x11
export SDL_VIDEODRIVER=x11
export QT_X11_NO_MITSHM=1
unset WAYLAND_DISPLAY

# ----- Runtime dir för KDE -----
export XDG_RUNTIME_DIR=${XDG_RUNTIME_DIR:-/tmp/runtime-$USER}
mkdir -p "$XDG_RUNTIME_DIR"
chmod 700 "$XDG_RUNTIME_DIR"

# ----- Ljud via WSLg PulseAudio -----
for s in \
  /mnt/wslg/PulseServer \
  /mnt/wslg/runtime-dir/pulse/native \
  "/mnt/wslg/run/user/$(id -u)/pulse/native"
do
  if [ -S "$s" ]; then
    export PULSE_SERVER="unix:$s"
    break
  fi
done

echo "DISPLAY=$DISPLAY"
echo "PULSE_SERVER=$PULSE_SERVER"

pactl info | sed -n '1,10p' || echo "PulseAudio hittades inte ännu."

exec dbus-run-session startplasma-x11
EOF
